# Mission Control

Fly a rocket into space together. The game is on the TV; everyone's phone
is a station on the bridge — Pilot, Shields, Gunner, Thrusters. Play alone
and the computer runs the seats nobody has taken. Get as far as you can,
spend the credits on a better ship, and go again.

Open `index.html` on the TV, scan the QR code with each phone, tap READY.

See `HANDOFF.md` for how it works and `CLAUDE.md` for the checks to run
before shipping.
